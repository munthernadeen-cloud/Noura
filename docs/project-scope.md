# Noura Project Scope

## Project Objective

Noura is a full-stack web application that allows users to create a personal account, track their Quran reading progress over a 30-day plan, and organize their own Duas and Adhkar in custom categories.

## In Scope

- User Sign Up
- User Login
- User Logout
- Forgot Password
- Quran 30-Day Tracker
- Mark Juz as Completed
- Undo Completion
- Save Quran Progress
- Custom Dua & Adhkar Categories
- Add Dua
- Add Dhikr
- Edit Entries
- Delete Entries
- Search Entries
- Dashboard Statistics
- Progress Chart
- Responsive Design
- User-Specific Data
- Secure Access
- Deployment

## Out of Scope

- AI Features
- Full Quran Reader
- Quran Audio
- Prayer Times
- Push Notifications
- Social Features
- Public Profiles
- Payments
- Mobile Application
- Admin Dashboard

## Future Features

- AI Progress Assistant
- Prayer Times
- Ramadan Mode
- Multiple Khatmah Plans
- Notifications
- Mobile Application
