# Noura

Noura is a full-stack Quran progress and personal Duas & Adhkar tracking web application.

## Project Goal

Noura helps users:
- Track Quran reading progress over a 30-day plan
- Create personal Dua and Dhikr categories
- Save and manage personal spiritual content
- View progress statistics
- Access their own data through a personal account
